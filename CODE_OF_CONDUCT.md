# Code of Conduct

## Nosso compromisso

Queremos que este projeto seja um espaço aberto, colaborativo e respeitoso para todas as pessoas que desejem contribuir.

Esperamos que todos os participantes ajam de forma profissional e construtiva, independentemente de experiência, conhecimento técnico ou nível de participação no projeto.

## Comportamentos esperados

São incentivados:

- Respeito às opiniões e contribuições de outras pessoas.
- Críticas construtivas.
- Colaboração e compartilhamento de conhecimento.
- Comunicação clara e respeitosa.
- Disposição para aprender e ajudar.
- Respeito às decisões dos mantenedores do projeto.

## Comportamentos não aceitáveis

Não serão tolerados:

- Assédio, ameaças ou intimidação.
- Ataques pessoais.
- Discriminação ou discurso de ódio.
- Publicação de informações privadas de outras pessoas sem autorização.
- Comportamento deliberadamente ofensivo ou disruptivo.
- Tentativas de prejudicar o projeto ou outros colaboradores.

## Discordâncias

Discordâncias sobre funcionalidades, código ou decisões do projeto são naturais e fazem parte do desenvolvimento colaborativo.

Procure apresentar argumentos técnicos e respeitar decisões diferentes das suas.

Os mantenedores poderão tomar decisões sobre a direção do projeto considerando seus objetivos, arquitetura, estabilidade e disponibilidade.

## Moderação

Os mantenedores podem remover comentários, Issues, Pull Requests ou outras contribuições que violem este código de conduta.

Em casos mais graves ou recorrentes, colaboradores poderão perder a possibilidade de participar do projeto.

## Reportando problemas

Caso você identifique um comportamento inadequado, entre em contato com os mantenedores do projeto pelos canais oficiais disponíveis no repositório.

Todas as situações serão analisadas de maneira responsável e, quando possível, com confidencialidade.

## Escopo

Este Código de Conduta se aplica às interações relacionadas ao projeto, incluindo o repositório GitHub, Issues, Pull Requests, discussões e demais canais oficiais associados ao projeto.

## Evolução deste documento

Este Código de Conduta pode ser atualizado conforme o projeto e sua comunidade evoluírem.
